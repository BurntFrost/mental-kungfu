# Category Taxonomy

Full reference for all 10 psychological categories in the Mental Kung Fu system.

---

## 1. REFRAME ↻

**Vector**: Flip their attack into your advantage
**Archetype**: Harvey Specter — redirect the courtroom
**Color**: `#3b82f6`
**When to use**: When someone takes a shot at you. Instead of blocking, redirect the energy so their attack becomes evidence of your superiority.

### Lines
| # | Line | Core |
|---|------|------|
| 1 | You don't like me? Want me to lower the difficulty for your comfort? | ◆ |
| 2 | Your criticism is just a map of your limitations. | |
| 3 | You didn't offend me. You auditioned — and didn't get a callback. | |
| 4 | That was supposed to hurt? Recalibrate. | |
| 5 | You tried to expose me. All you did was advertise me. | |
| 6 | You think you're testing me. I'm the one grading. | |

---

## 2. SCALE △

**Vector**: Establish you operate on a different plane
**Archetype**: John Wick — the legend precedes the man
**Color**: `#8b5cf6`
**When to use**: When someone tries to compare themselves to you or compete. Reframe the comparison as a category error — you're not on the same axis.

### Lines
| # | Line | Core |
|---|------|------|
| 1 | I'm not intimidating. You're just underprepared for the room you walked into. | ◆ |
| 2 | You can't put me in a box — I built the warehouse. | ◆ |
| 3 | You brought a ladder. I own the building. | |
| 4 | Your ceiling is my foundation. | |
| 5 | You measured the room. I designed the blueprint. | |
| 6 | You're competing for a seat. I built the table. | |

---

## 3. TEMPO ◉

**Vector**: Show you're already three moves ahead
**Archetype**: Wick silence — action already in motion
**Color**: `#ef4444`
**When to use**: When someone is still planning, talking, or posturing. Demonstrate that you've already executed and moved on. Time asymmetry as a weapon.

### Lines
| # | Line | Core |
|---|------|------|
| 1 | I don't talk about what I'm going to do. I just let you watch. | ◆ |
| 2 | By the time you understood the move, I'd already made the next three. | |
| 3 | You're rehearsing. I'm already in post-production. | |
| 4 | You're loading. I've already shipped. | |
| 5 | You finished planning. I finished executing. Tuesday. | |
| 6 | You're building momentum. I'm already coasting on results. | |

---

## 4. INDIFFERENCE ◌

**Vector**: Erase them from the equation entirely
**Archetype**: Wick walking past the body
**Color**: `#64748b`
**When to use**: When someone is trying to matter to you — trying to be your rival, your obstacle, your concern. The cruelest response isn't defeat; it's irrelevance.

### Lines
| # | Line | Core |
|---|------|------|
| 1 | You're not in my way. I just keep forgetting you're here. | ◆ |
| 2 | I'd explain, but I don't onboard tourists. | |
| 3 | You're not background noise. Background noise is consistent. | |
| 4 | I don't have enemies. I have people I haven't noticed yet. | |
| 5 | I didn't ignore you on purpose. You just weren't a variable. | |
| 6 | You keep showing up. I keep not adjusting. | |

---

## 5. DISMISSAL ⊘

**Vector**: Acknowledge and discard in one breath
**Archetype**: Harvey's "get out of my office"
**Color**: `#f59e0b`
**When to use**: When someone has made their best effort and it wasn't enough. You see it, you note it, you move on. The acknowledgment is what makes the dismissal sting.

### Lines
| # | Line | Core |
|---|------|------|
| 1 | Nothing personal. You're just playing a different game at a different difficulty. | ◆ |
| 2 | I don't punch down. I don't even look down. | |
| 3 | You came to compete. I came to collect. | |
| 4 | Cute strategy. Did it come with instructions? | |
| 5 | Your best move was interesting. My default was better. | |
| 6 | That was your A-game? I was warming up the bench. | |

---

## 6. STOIC ◇

**Vector**: Weaponize calm — let stillness do the damage
**Archetype**: Marcus Aurelius — the emperor doesn't flinch
**Color**: `#06b6d4`
**When to use**: When chaos is swirling and someone expects you to react. Your non-reaction is the statement. Discipline as dominance.

### Lines
| # | Line | Core |
|---|------|------|
| 1 | I don't get even. I get distance. The gap is the punishment. | ◆ |
| 2 | Your chaos isn't my emergency. | |
| 3 | I don't react. I adjust. There's a difference you'll learn too late. | |
| 4 | Pressure doesn't build diamonds. Discipline does. I'm the proof. | |
| 5 | I removed you from the equation. The math got better. | |
| 6 | Your turbulence is not my weather. | |

---

## 7. INEVITABILITY ⊞

**Vector**: Frame the outcome as already decided
**Archetype**: Wick's pencil — it was always going to end this way
**Color**: `#10b981`
**When to use**: When someone thinks they still have a chance. Remove hope by framing the result as physics — not effort, not luck, just gravity doing its thing.

### Lines
| # | Line | Core |
|---|------|------|
| 1 | I already know how this ends — you're still hoping. | ◆ |
| 2 | This isn't a contest. It's a schedule — and you're not on it. | |
| 3 | You're still in the negotiation phase. I'm in the delivery phase. | |
| 4 | I don't rush because the outcome already has my name on it. | |
| 5 | The result was decided before you entered the room. I just haven't filed the paperwork. | |
| 6 | I don't race. I set the finish line. | |

---

## 8. CONTROL ⊕

**Vector**: Demonstrate mastery over the system itself
**Archetype**: Tyler Durden — I rewrote the rules
**Color**: `#ec4899`
**When to use**: When someone thinks they're clever for working within the system. You don't play the game — you designed it. Meta-dominance.

### Lines
| # | Line | Core |
|---|------|------|
| 1 | I don't play the odds. I already see the board. | ◆ |
| 2 | You follow the playbook. I write the errata. | |
| 3 | You learned the rules. I designed the constraints. | |
| 4 | You found a loophole. I built the loop. | |
| 5 | You're playing chess. I'm playing the chess player. | |
| 6 | The game changed. You weren't notified. | |

---

## 9. EXISTENTIAL ◈

**Vector**: Turn their own mind against them
**Archetype**: Tyler Durden — the mirror that fights back
**Color**: `#f43f5e`
**When to use**: When you want the line to keep working after you've left. These are delayed detonations — the listener walks away and realizes the damage is self-inflicted.

### Lines
| # | Line | Core |
|---|------|------|
| 1 | You're not afraid of me. You're afraid of what I prove about you. | ◆ |
| 2 | I didn't break your confidence. I just showed you where it was already cracked. | |
| 3 | You don't hate me. You hate that I'm the standard you can't meet. | |
| 4 | Every time you doubt me, you're really confessing about yourself. | |
| 5 | I'm not your enemy. I'm the mirror you keep trying to walk past. | |
| 6 | You wanted to find my weakness. You found your own instead. | |

---

## 10. IDENTITY ⬡

**Vector**: Define yourself so completely they can't
**Archetype**: All three — Wick's reputation, Durden's philosophy, Harvey's brand
**Color**: `#a855f7`
**When to use**: The only category that doesn't require an opponent. These are self-definition statements so complete that no one else can write your label. Pure offensive — you're not responding to anything, you're declaring.

### Lines
| # | Line | Core |
|---|------|------|
| 1 | I'm not motivated. I'm engineered. | |
| 2 | I wasn't built for comfort. I was built for output. | |
| 3 | I don't have a backup plan. The first one works. | |
| 4 | I'm not lucky. I'm what prepared looks like from the outside. | |
| 5 | I don't fit in. I was never designed to. | |
| 6 | They didn't make me. I compiled myself. | |
